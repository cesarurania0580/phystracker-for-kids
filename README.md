# PhysTracker for Kids — static classroom edition

This independent copy runs directly in a browser or on GitHub Pages. It includes Record, Calculate, Graph, and Explain, with the five-part science checklist. It has no AI feedback, backend, API key, or package installation requirement.

Open `index.html` locally, keeping the `assets` folder beside it. Measurements, calculations, bars, and writing stay in place when moving between steps. Reloading or closing the page clears the session. This app does not submit student writing or measurements to a service.

## Publish on GitHub Pages

1. In this repository, open Settings → Pages. Select Deploy from a branch, then `main` and `/ (root)`, and save.
2. Wait for the Pages deployment, then open the URL shown in Settings → Pages: `https://cesarurania0580.github.io/phystracker-for-kids/`.

This repository publishes only the static edition. The AI-enabled edition is maintained separately and is not included here. Changes are not synchronized automatically between the two copies.
